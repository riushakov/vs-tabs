# VS_Tabs

Переключение между проектами в одном окне VS Code с сохранением вкладок и терминалов.

## Команды

- `VS_Tabs: Добавить папки как проекты`
- `VS_Tabs: Добавить текущую папку как проект`
- `VS_Tabs: Переключить проект`
- `VS_Tabs: Удалить проект из списка`
- `VS_Tabs: Обновить список`

## Возможности

- Список проектов в боковой панели и статус-баре
- Переключение между проектами в одном окне
- Сохранение и восстановление открытых вкладок (с учётом групп редакторов)
- Один терминал на проект, открывается в папке проекта
- Горячие клавиши: `Ctrl+Alt+P` (переключить), `Ctrl+Alt+A` (добавить текущую папку)
